# OUTPOST — ระบบจัดการหลายร้านในที่เดียว (สำหรับผู้ใช้คนเดียว)

เว็บแอปจัดการ **หลายร้านที่ต่างประเภทกัน** (เช่น ร้านคอม / ร้านซ่อมมือถือ / ร้านขายข้าว)
ในแดชบอร์ดเดียว สร้างด้วย **React + Vite** ยังไม่ต่อหลังบ้าน
ใช้ข้อมูลจำลอง (mock) และบันทึกลง `localStorage` ของเบราว์เซอร์

> แต่ละร้านมีสินค้าเป็นของตัวเอง และ **สร้าง/แก้ไข/ลบร้านได้เอง** ผ่านหน้าจอ

## ฟีเจอร์
- **สร้างร้านเอง** — กดปุ่ม `＋` มุมขวาบน ตั้งชื่อ เลือกไอคอน/สี เพิ่มร้านได้ไม่จำกัด
- **ภาพรวม (Dashboard)** — ยอดขายรวม / กำไรสุทธิ / ค่าใช้จ่ายรวมทุกร้าน, กราฟเปรียบเทียบร้าน, แจ้งเตือนด่วน, สลับดูทีละร้านที่มุมขวาบน
- **สต็อก (Inventory)** — สินค้าแยกตามร้าน, เพิ่ม/แก้ไข/ลบสินค้า, แจ้งเตือนใกล้หมด/หมด, ปรับจำนวน และ **โอนย้ายสินค้าข้ามร้าน**
- **การเงิน (Finance)** — บันทึกรายรับ-รายจ่ายแยกร้าน, คำนวณกำไรสุทธิ, สรุป **ปิดยอดเงินสดสิ้นวัน**
- **สถิติ (Analytics)** — สรุปยอดขาย (วัน/สัปดาห์/เดือน), กราฟแนวโน้ม + **คาดการณ์ล่วงหน้า 3 วัน**, สินค้าขายดี
- **บันทึกด่วน** — ปุ่มลอย (FAB) เปิดฟอร์มบันทึกรายรับ/รายจ่ายได้ทุกหน้า
- **Responsive** — ออกแบบ mobile-first ใช้งานสะดวกบนมือถือ/แท็บเล็ต

## วิธีรัน
```bash
npm install
npm run dev
```
เปิด http://localhost:5173

## โครงสร้าง
```
src/
  main.jsx            จุดเริ่มต้น
  App.jsx             โครงหลัก + แถบเมนูล่าง + store switcher
  store.jsx           state กลาง + mock data (Context)
  index.css           ธีม/สไตล์ทั้งหมด
  components/
    Dashboard.jsx     หน้าภาพรวม
    Inventory.jsx     หน้าสต็อก (แยกตามร้าน)
    ProductSheet.jsx  ฟอร์มเพิ่ม/แก้ไขสินค้า
    TransferSheet.jsx ฟอร์มโอนย้ายสินค้าข้ามร้าน
    StoreSheet.jsx    ฟอร์มสร้าง/แก้ไข/ลบร้าน
    Finance.jsx       หน้าการเงิน
    TxSheet.jsx       ฟอร์มบันทึกรายรับ/รายจ่าย
    Analytics.jsx     หน้าสถิติ + กราฟ
```

## ขั้นต่อไป (เมื่อจะต่อหลังบ้าน)
